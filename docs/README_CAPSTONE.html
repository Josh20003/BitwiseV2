Why Bitwise

Foundational courses in Computer Science and Computer Engineering—specifically Digital Logic Design, Discrete Mathematics, and Computer Architecture—have long suffered from two major learning bottlenecks:

Students struggle with abstract mental models: binary borrow cascades, two's complement sign wrapping, Gray code reflections, and Karnaugh map grouping rules are difficult to master on static presentation slides or textbooks. Furthermore, students spend hours verifying homework steps manually with no real-time diagnostics when a calculation errors out.

Bitwise addresses both ends of the educational pipeline. Learners interact with reactive digital representations (toggling bits directly, observing real-time ALU overflow flags, and watching mathematical division cascades), while the platform’s adaptive AI tracks concept mastery via Bayesian Knowledge Tracing (BKT) and Exponential Moving Average (EMA) to dynamically target problem areas.

North-star outcomes

  • Students: Intuitive conceptual mastery of digital logic and binary representations without rote memorization.
  • Intermediate Step Verification: Instantaneous verification of mathematical traces (carries, borrows, parity syndromes) in sub-seconds.
  • Self-Paced Mastery: Continuous progress tracking across 5 skill levels (Novice → Expert).

Features

1 · Educational Scaffolding (11 Structured Lessons)

Structured interactive curriculum covering the complete digital logic syllabus:

  • Lessons 1–3: Number Systems, Digit Groupings (bits, nibbles, bytes), and Number System Conversions with focused practice challenges.
  • Lesson 4: Binary Arithmetic Workspace: vertical notation, carry/borrow steps, multiplication, and long-division trainers.
  • Lessons 5–7: 1's & 2's Complements, Signed/Unsigned Ranges, and Binary Codes (BCD, Gray Code, ASCII).
  • Lessons 8–11: Boolean Algebra Explorer, Logic Gate Simulator, Truth Table Builder, and interactive 2-, 3-, 4-variable Karnaugh Maps (K-Maps).

2 · Multi-Mode Calculation Laboratory

Dynamic tools providing mathematical proof steps:

  • Universal Radix Converter: Translates between Binary, Octal, Decimal, Hexadecimal, and arbitrary bases (2–36) with algorithmic step cards.
  • 1's & 2's Complement Negation: Inversion visualizer, end-around carry cascade, and sign-magnitude comparative matrices.
  • Hardware ALU Flags: Real-time detection of Carry (C), Overflow (V), Zero (Z), and Sign (S) flags.

3 · Binary Codes & Error Correction

Hands-on encoding schemes and error-detecting protocols:

  • Hamming(7,4) Code: Single-bit error detection and syndrome parity correction with interactive bit-flipping simulator.
  • BCD & Gray Code: 4-bit decimal translation and single-bit transition encoder/decoder.

4 · Adaptive AI Assessment & Ask AI Tutor

Intelligent, personalized student evaluation:

  • Bayesian Knowledge Tracing (BKT): Dynamically calculates learner mastery probabilities based on previous attempts.
  • Context-Aware AI Tutor: Socratic question-answering powered by Google Gemini and Groq API, providing step explanations without spoiling direct answers.

Across the app

  • Cohesive Dark Theme: Styled with tailored HSL tokens (#090d18 and #0c101d) and purple/indigo accents.
  • Zero Secret Exposure: All database credentials, LLM keys, and service tokens are kept securely server-side.
  • Strict Type Safety: Validated with TypeScript npx tsc -b with 0 compile errors across frontend and backend.

Module boundaries

  • Frontend Independence: Client components interact strictly through the typed REST API; direct database connections from the browser are blocked.
  • Stateless Calculation Engine: Core binary arithmetic and conversions run entirely as deterministic in-memory algorithms with sub-5ms latency.
  • Connection Pooling: Database queries flow through Supabase's PgBouncer pooler on port 6543 to eliminate connection starvation during concurrent quizzes.

Principles the code holds to

  • Strict Type Safety: Zero tolerance for loose any types in binary calculations to prevent floating-point inaccuracies.
  • Deterministic Core: Calculation tools execute in local TypeScript algorithms; they never fail even if third-party AI APIs experience network downtime.
  • Connection Pooling: Prisma strictly communicates through Supabase's PgBouncer pooler to prevent PostgreSQL thread exhaustion under concurrent classroom usage.
  • Pedagogical Value: Intermediate mathematical steps (carries, borrows, parity syndromes) are always computed and returned in response payloads.
