Bitwise: Deployed System

Bitwise capstone, deliverable 1: Working Software and Deployment. Status as of 18 October 2026.
Bitwise is deployed and running in production. Students, educators, and evaluators use the web platform at bitwise.live, served by one backend API at bitwise.live/api. Cloud database storage and user authentication are powered by Supabase PostgreSQL in the Tokyo region. The adaptive assessment engine integrates Google Gemini and Groq Cloud. Access notes

  • Website: open https://bitwise.live and log in at /login. Admins and educators land on their respective consoles at /admin.
  • Interactive lessons & scaffolding: navigate to /lessons to access all 11 digital logic and computer organization modules. Interactive practice activities (such as Decimal-to-Binary in Lesson 3) provide real-time input verification and mathematical feedback.
  • Multi-mode calculators: available publicly at /calculator and /converter. Evaluators can perform arbitrary base conversions (bases 2–36) and vertical binary arithmetic with step-by-step mathematical proof traces without creating an account.
  • Adaptive AI quizzes: when taking quizzes, the engine dynamically calculates Bayesian Knowledge Tracing (BKT) probabilities and Exponential Moving Average (EMA) scores. Socratic hints are generated via Google Gemini / Groq without revealing direct answers.
  • Staging / offline presentation: for panel demonstrations during network constraints, the full stack can be run locally using the local dev servers (bitwise-ui on port 5173, bitwise-server on port 3000) with identical feature parity.
